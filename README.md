# Repositorio_LLMs

Este repositorio reúne los artefactos, archivos de soporte y scripts de ejecución correspondientes a la evaluación experimental de modelos de lenguaje en tareas de generación de documentación técnica. La estructura del proyecto comprende el dataset original alojado en el directorio dataSet, las configuraciones metodológicas de los prompts parametrizados en prompts.xlsx y el registro consolidado de peticiones a la API en openrouter_activity.csv. El entorno de interfaz e interacción programática se compone de las herramientas de código fuente en interfaz_LLMs.py.

Con el propósito de cumplir los estándares de seguridad computacional y prevenir la divulgación involuntaria de credenciales de acceso, todas las llaves de interfaz de programación de aplicaciones (API keys) vinculadas a los servicios de Hugging Face, GitHub y OpenRouter fueron removidas del código fuente público. Las funciones de invocación en interfaz_LLMs.py leen las credenciales mediante variables de entorno del sistema operativo. Para ejecutar los módulos de forma local, el investigador debe configurar previamente las claves requeridas en sus respectivas variables antes de iniciar el entorno de ejecución.
